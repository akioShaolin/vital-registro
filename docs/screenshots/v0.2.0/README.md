## Como interpretar as imagens

As telas mostram a Home, histórico dos três tipos, formulário, seletores, contextos de glicemia, gráficos e rótulo de diastólica. As prévias exibem 34 registros novos válidos e, em outro arquivo, 8 duplicatas idênticas. Elas documentam esses estados visuais; não comprovam isoladamente gravação, persistência após reinício, rollback, round-trip completo ou todos os caminhos do SAF.

Nos seletores rolantes, a primeira linha visível aparece parcialmente cortada abaixo dos títulos das colunas. O recorte não retoca esse comportamento. O formulário de pressão e o menu de contextos estão em posições de rolagem específicas; não representam a tela completa de todos os campos.

A captura com pressão/pulso/peso combinados no mesmo registro pertence ao modelo antigo e não integra esta galeria. As capturas históricas v0.1.0 estão no [índice anterior](../README.md#capturas-históricas-v010).
